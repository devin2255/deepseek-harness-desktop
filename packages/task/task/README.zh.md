# @deepseek-ai/dsh-task

[English](README.md) | 中文

这是根任务、验收标准、证据、风险、评审决策和统一注意力行的持久词汇。任务事实使用全值 Session 事件，因此回放不依赖进程本地状态。证据指向根任务树中的准确事件序号。

## 模型体验

无直接影响，因为任务事件仅作为日志事实存在，不进入模型请求或模型可见的 Session 表面。

#### KV 缓存影响

没有影响。记录或回放任务事实不会改变提供方请求。

## 已知限制与待完成工作

- 此包当前仅定义值和事件，尚不包含跨会话 Provider 与 Host API。
- 严格回放校验与关系不变式随任务折叠器一同提供。
