# @deepseek-ai/dsh-client-ui-task-review

[English](README.md) | 中文

独立 Task 审查工作区的参考文档。插件占用 `shell.review`，并消费客户端运行时的当前审查投影。它展示变更文件、受限的统一 Diff、分支与基准信息、验收条件、验证证据引用、未解决风险和持久交付回执。审查数据保留在不依赖 React 的 Task 运行时中；组件通过注入 props 仅接收一个 observable 与收窄后的回调。

刷新后，只要已选路径仍然存在，文件列表就会保留该选择。二进制和截断响应会被显式标记。Patch 文本在移除终端控制序列和非排版控制字符后按纯文本渲染；组件不解释 HTML，也不创建文件系统链接。断连时保留最后一次审查并标记为过期，重连时刷新；结构化 Host 错误保持可重试。Apply 冲突会明确说明源检出保持不变。

“要求修改”“创建提交”“应用到项目”和“丢弃工作树”是彼此独立的操作。每项操作都有确认步骤。Commit 说明它只改变任务工作树。Apply 说明源目录必须干净、HEAD 不得变化，并且必须通过三方预检。Discard 区分无法恢复的未提交内容与任务分支上保留的提交。操作成功后展示 Task 的持久回执，不根据本地 UI 状态推断完成。

## 模型体验

无。这个浏览器侧 Task 审查与交付界面不注册模型输入或交互响应。

#### KV Cache 影响

无；该包既不组装也不发送模型请求。

## 已知限制与暂缓事项

- 尚不支持按文件或 hunk 暂存；Commit 针对完整且精确的审查 revision。
- 验证证据展示持久 Session 与序号引用；尚不能直接跳转到对应记录。
- 尚不支持 Diff 搜索与并排视图。
