# @deepseek-ai/dsh-client-ui-task-overview

[English](README.md) | 中文

桌面任务总览插件。它占用布局的可选 `shell.home` slot，并在 `sidebar.footer.action` 中添加常驻的任务入口，侧栏收起时也可使用。Desktop 组合包安装此插件，普通 Web 组合包不安装。该包没有配置项。

在 Desktop profile 中，总览消费运行时的权威 Task 投影。每行展示用户定义的目标（旧根会话没有定义时回退到根 Session 标题）、已注册 Workspace、六种派生 Task 状态之一、活跃后代数量、已满足或豁免的验收条件进度、未解决风险数量，以及实时、断连或不可用的新鲜度。需要处理和失败的行归入“需要你处理”，活跃行归入“进行中”，评审中、可以交付和已结束的行归入“其他”；每组保留 Host 顺序。Workspace 归档集合中的根会话不会显示在总览中，权威 Task 行仍然保留。其他组合缺少 Task hook 时，明确显示“仅显示会话活动”，使用旧的纯 Session selector，且不声称验收条件、风险、评审就绪度或 Task 新鲜度。

每个注意事项都有指向其准确 owner Session 的导航操作。根 Session 使用普通导航；subagent 使用已保留的目录地址，必要时仅刷新已知直接父级的目录一次。可选的隔离桌面桥接会保留最新的原生通知目标，直到权威 Session 目录就绪，再通过同一个导航控制器处理；当前尝试失败时会打开“任务”页并在警告中保留可读错误，直到成功或后续尝试将其清除。普通 Web 组合没有该桥接，也不订阅桌面导航。处于评审中、可以交付或已结束状态的隔离 Task 还提供“审查变更”，它会先加载运行时审查对象，再打开独立审查工作区。地址或审查缺失或被拒绝时，总览保留可读错误。后续导航或插件 dispose（资源释放）会阻止尚未完成的查询打开会话或审查页。导航不会回答问题、授予审批、将评审标为就绪或清除注意事项。

新建任务可显式选择已注册的 Workspace，也可先使用运行时当前或最近 Workspace，再进入已有的目录设置流程。确定 Workspace 后默认请求应用所有的 Git worktree，并仅在 Host 接受后打开新 Session。隔离失败会留在总览中，展示 Host 提供的用户安全诊断，以及明确的“重试隔离”和“直接使用项目”选项；客户端绝不会静默改用直接模式。焦点会进入恢复面板，并在重试成功后返回“新建任务”。Task 行保留已注册的 Workspace 标题，将已分配的执行路径标记为“工作树”，悬停文字提供准确路径。刷新会请求 Task、Session 和 Workspace 三份镜像。初次加载、已同步的空列表、刷新失败、保留的陈旧条目和传输断连有不同提示；连接断开或数据加载中会禁用刷新和新建任务。结构化 Task 命令错误保持可读。

## Model Experience

None, as 此插件仅展示客户端元数据并调用已有导航操作，不贡献模型输入。

#### KV Cache effect

无；该包不组装或发送模型请求。

## Known Limitations and Deferred Work

- 活跃后代展示使用已有 Session 摘要；Task Provider 负责后代成员关系和注意事项聚合。
- 归档任务没有总览或取消归档入口；已完成 worktree 的合并、移除和修复控制仍为后续工作。
