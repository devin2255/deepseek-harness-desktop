# @deepseek-ai/dsh-client-ui-task-overview

[English](README.md) | 中文

桌面任务总览插件。它占用布局的可选 `shell.home` slot，并在 `sidebar.footer.action` 中添加常驻的任务入口，侧栏收起时也可使用。Desktop 组合包安装此插件，普通 Web 组合包不安装。该包没有配置项。

总览从运行时列出的会话 id 中派生普通、非空且未归档的任务。工作区名称依据注册表成员关系，不匹配目录。已知后代只沿连续的 subagent 来源父级链计入；普通 fork 仍是独立任务。任务或已知后代有待处理的审批、计划审阅或问题时，归入“需要你处理”；否则任务或已知后代正在运行时，归入“进行中”；其余归入“其他”。每组按最近更新时间降序、再按会话 id 排序。未读动态只是提醒，不表示执行成功或已可审阅。

每个待处理会话都有导航操作。普通任务使用会话导航；subagent 使用已保留的目录地址，必要时仅刷新已知直接父级的目录一次。地址缺失或被拒绝时，总览保留可读错误。后续导航或插件 dispose（资源释放）会阻止尚未完成的地址查询打开会话。这些操作不会提交交互响应。

新建任务可显式选择已注册的工作区，也可沿用运行时当前或最近工作区与目录设置流程。任务直接在所选目录中运行，不会自动创建隔离的 worktree。刷新会请求两份元数据列表。初次加载、已同步的空列表、失败和保留的陈旧条目有不同提示；连接断开或元数据加载中会禁用刷新和新建任务。运行时错误详情保持可读。

## Model Experience

None, as 此插件仅展示客户端元数据并调用已有导航操作，不贡献模型输入。

#### KV Cache effect

无；该包不组装或发送模型请求。

## Known Limitations and Deferred Work

- 只有已知的 subagent 摘要贡献待处理状态和运行数量；总览不枚举日志，也不轮询尚未发现的目录。
- 归档任务没有总览或取消归档入口，该插件也不管理隔离的 worktree。
