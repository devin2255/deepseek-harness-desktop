# Agent Note: 隔离写入者成果审查

Status: implemented

[English](2026-10-07-isolated-writer-result-review.md) | 中文

## 问题

[隔离写入者](2026-10-06-isolated-subagent-writer-preparation.md) 将更改保留在根检出之外。仅面向根任务的审查工作区无法检查这些成果，而把子级摘要当作根任务会对错误身份授权交付。冷态子级还需要独立于普通 Session 列表的发现方式。

## 决策

既有 Host 审查读取在必需的根 id 之外接受可选子 Session id。Host 从 fork seed 之后读取子级自身执行记录，并验证来源、直接父级、分配所有者、Workspace、源 worktree 和执行 cwd。它在读取 Git 前拒绝已丢弃的根、缺少分配及任何仍驻留的子级，并在异步读取后再次检查驻留状态。持久化检查绝不激活任一 Agent（智能体）。本地审查提供方继续验证精确 Git 身份、revision、路径和输出上限。

客户端审查所有者分别存储根与子级身份。摘要和 Diff 调用仍以父级寻址，任一选择变化都会使较早读取失效。子级检查拒绝根任务交付命令。活动交付阻止选择变化；断连使其响应代次失效，因此迟到回执不能替换另一个可见审查。刷新 Task 投影失败时，已确认回执仍保持接受，刷新错误独立显示。

审查选择器挂载时观察既有的持久直接子级目录，离开时释放观察。刷新重新读取目录与审查。健康目录条目无需列表成员身份即可发现；运行中条目禁用，诊断条目省略，目录失败保持可见。Host 归属校验是权威，包括对不活跃但仍驻留的子级和共享目录子级的校验。子级视图明确标记只读，禁用根操作，并隐藏根交付成功信息。验收条件和风险继续描述根目标。

## 考虑过的替代方案

**读取客户端指定目录。** 不予采纳，因为路径不能建立根归属。执行身份由子级日志和实时 Git 注册确定。

**把子级摘要 id 用作根请求 id。** 不予采纳，因为根生命周期和交付回执属于父 Task。选择器增加读取目标，不重新分配 Task。

**仅从 Session 列表发现子级。** 不予采纳，因为持久冷态子级可能不在该列表中。发现归既有的父级寻址目录所有。

## 后果

人工检查与[写入者集成工具](2026-10-07-batch-writer-integration.md) 共享提供方，不增加模型输入、Session 事件、Renderer 文件系统权限或第二个成果数据库。准备、续行、批量发布和[根交付](2026-09-13-task-review-delivery.md) 记录继续活跃，因为各自拥有不同决策。[集成历史](2026-10-08-task-integration-history.md) 提供冲突注意事项及贡献者检查入口。桌面写入者仍需显式启用。子级提交和集成控件、冲突解决、执行租约、孤立目录恢复及完整桌面写入者验收仍未完成。

## 验证

Host 测试在提供方执行前拒绝外来归属、仅继承 seed、共享目录、活动、已恢复及根已丢弃的读取，并覆盖实时与冷态检查。客户端测试覆盖父级寻址读取、读取和变更代次隔离、禁用交付、目录发现与生命周期以及显式错误。真实 Loader 写入者场景驱动实际 Git 与文件系统工具，拒绝活动子级审查，随后通过 fetch 载体读取已释放子级的摘要和 Diff，且不激活 Agent。

Electron 验收在普通桌面组合旁显式启用隔离写入者，执行实际文件系统工具，并通过具有明确无障碍名称的审查对象控件选择已停止子级。它验证渲染的 Diff、刷新后保留的选择、禁用的根任务交付操作、切回根任务后恢复的控件，以及保持不变的源和根检出。完整桌面生命周期仍达到进程完全停稳。这些检查不能证明真实模型执行或子级提交和集成界面验收。
